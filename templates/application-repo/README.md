# <Company> · <Role>

In-depth application and interview materials for a Tier A role. Status lives in the job tracker, not here.

## Rule
Every claim used in a deck or interview must appear in `_brand/evidence-ledger.md`, and must not appear in `_brand/do-not-say.md`.

## Contents
| File | What it is |
|---|---|
| `_brand/brandscript.md` | Approved BrandScript (copy) |
| `_brand/evidence-ledger.md` | Claims with evidence status (copy) |
| `_brand/do-not-say.md` | Retired or unverified claims |
| `01-jd.md` | Posting snapshot |
| `02-company-research.md` | Facts, inferences, hypotheses |
| `03-fit-map.md` | Needs → proof → boundaries |
| `04-pitch-kit.md` | Company StoryBrand, intros, gaps, 90-day plan, questions |
| `05-deck-outline.md` | Slides and speaker notes |
| `06-interview-notes.md` | Per-round notes and lessons |
| `research/` | Original research files |

## Refresh rule
When the BrandScript changes, recopy `_brand/` first.
