# Clarity audit

Score each criterion 1 to 5. Give a one-line reason and a fix. Scores are editorial judgments, not measurements.

| Criterion | Question |
|---|---|
| Audience identified | Is it obvious who this is for? |
| Audience is the hero | Does the copy talk about their win more than the candidate's résumé? |
| Problem is obvious | Would the reader recognize their problem in one read? |
| Internal concern | Does it speak to how the problem feels? |
| Empathy + authority | Are both present, and is authority backed by proof? |
| Plan is simple | Three steps, plain words? |
| CTA is clear | One action, worded the same everywhere? |
| Stakes realistic | Proportionate and evidenced? |
| Success explicit | Can the reader picture the result? |
| Plain language | Free of jargon in headlines? |
| Nothing extra | Can anything be cut? |
| Results over activities | Outcomes, not task lists? |

End with the top 3 fixes, ordered by impact.
